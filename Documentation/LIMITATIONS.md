# TrainETA — Limitations and Responsible Claims

## Current Limitations

- Prototype live-data access depends on the current external provider.
- Production requires authorized railway operational data access.
- Historical accuracy is not a guarantee of live accuracy.
- Same-journey actual arrival validation is not yet available for every live journey.
- Some operational effects use available proxies.
- Further live validation is required before operational deployment.

## Claims We Do Not Make

TrainETA does not claim:

- 99% prediction accuracy
- Direct access to Indian Railways operational APIs
- That RailRadar is an official Indian Railways API
- Direct preceding-train tracking where only a proxy is available
- Production-ready railway control or signalling functionality

## Recommended Positioning

TrainETA is a data-driven ETA prediction prototype demonstrating how live information, historical delay intelligence and route information can be combined to produce dynamic station-wise arrival forecasts.
